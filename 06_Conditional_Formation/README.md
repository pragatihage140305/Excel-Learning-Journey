# 🎨 Conditional Formatting in Excel

## 📌 Overview

In this lesson, I learned about **Conditional Formatting** in Microsoft Excel.

Conditional Formatting is used to automatically change the appearance of cells based on specific conditions. It helps to identify important values, patterns, duplicates, and trends quickly.

---

## 🔍 What is Conditional Formatting?

Conditional Formatting allows Excel to apply formatting automatically when a particular condition is satisfied.

Instead of manually formatting each cell, Excel can identify the required cells and apply the selected formatting.
