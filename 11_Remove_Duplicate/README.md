# 🧹 Remove Duplicates, Text to Columns & Flash Fill

## 📌 Overview

In this lesson, I learned three useful Excel features for cleaning and organizing data:

- Remove Duplicates
- Text to Columns
- Flash Fill

These features are useful for data cleaning and preparing datasets for analysis.

---

## 1. 🗑️ Remove Duplicates

I learned how to identify and remove duplicate records from an Excel dataset.

### What I Practiced

- Identifying duplicate values
- Selecting the required columns
- Using the **Remove Duplicates** feature
- Keeping unique records
- Understanding that duplicate records can affect data analysis

### Example

If the same student record appears more than once, Remove Duplicates can be used to keep only one unique record.
