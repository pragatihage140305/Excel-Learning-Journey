# ✅ Data Validation in Excel

## 📌 Overview

In this lesson, I learned about **Data Validation in Microsoft Excel**.

Data Validation helps control what type of information can be entered into a cell. It is useful for reducing incorrect entries and maintaining consistent data.

---

## 🔍 What is Data Validation?

Data Validation is an Excel feature used to set rules for cell input.

For example, we can restrict a cell to:

- A specific list of values
- A specific number
- A specific date
- A specific text length

This helps improve data accuracy and consistency.
