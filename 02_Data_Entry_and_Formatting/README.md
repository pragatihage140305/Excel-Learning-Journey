# 📝 Data Entry and Formatting

## 📌 Overview

In this topic, I practiced entering and managing data in Microsoft Excel using a student marks dataset.

The dataset contains the following columns:

* Sr.No
* Name of Student
* Sub 1
* Sub 2
* Sub 3
* Total

---

## 📊 Data Entry

I entered student serial numbers and names into the worksheet.

For the subject marks, I used a random number formula to generate marks.

---

## 🔢 Formula Used

```excel
=RANDBETWEEN(10,100)
```

This formula generates a random number between **10 and 100**.

I used this formula to generate marks for:

* Sub 1
* Sub 2
* Sub 3

---

## ⌨️ Keyboard Shortcuts Practiced

### Ctrl + R

Used to copy or fill data from the left cell towards the right.

I used `Ctrl + R` to copy the formula across the subject columns.

### Ctrl + D

Used to copy or fill data from the cell above to the cells below.

I used `Ctrl + D` to apply the formula to all student rows.

---

## 🔒 Converting Formulas to Fixed Values

The `RANDBETWEEN()` function changes the generated numbers whenever the worksheet recalculates.

To keep the marks fixed, I converted the formulas into values using:

**Copy → Paste Special → Values**

---

## 🎨 Formatting

I also practiced basic formatting to organize the student marks data and improve readability.

## 🎯 Key Learnings

* Entering data in Excel
* Using the `RANDBETWEEN()` function
* Using `Ctrl + R` to fill data to the right
* Using `Ctrl + D` to fill data down
