# 🔢 Essential Excel Formulas

## 📌 Overview

In this topic, I learned and practiced some essential Excel formulas using a student marks dataset.

The dataset contains marks for three subjects, and I used different formulas to calculate the total, maximum marks, minimum marks, average, percentage, and result.

---

## 📊 Dataset

The student marks table contains:

* Sr.No
* Name of Student
* Sub 1
* Sub 2
* Sub 3
* Total
* Max
* Min
* Average
* %Age
* Result

---

## 🔢 Formulas Practiced

### 1. SUM

Used to calculate the total marks of three subjects.

```excel
=SUM(C2:E2)
```

---

### 2. MAX

Used to find the highest mark among the three subjects.

```excel
=MAX(C2:E2)
```

---

### 3. MIN

Used to find the lowest mark among the three subjects.

```excel
=MIN(C2:E2)
```

---

### 4. AVERAGE

Used to calculate the average marks.

```excel
=AVERAGE(C2:E2)
```

---

### 5. Percentage

Used to calculate the percentage based on the total marks.

```excel
=F2/300*100
```

---

### 6. IF Function

Used to determine whether a student has passed or failed.

```excel
=IF(J2>=35,"Pass","Fail")
```

---

## ⌨️ Practice

After applying the formulas to the first student, I used Excel's fill feature to apply the formulas to the remaining students.

---

## 🎯 Key Learnings

* Using the `SUM()` function
* Using the `MAX()` function
* Using the `MIN()` function
* Using the `AVERAGE()` function
* Calculating percentages
* Using the `IF()` function
* Applying formulas to multiple rows
