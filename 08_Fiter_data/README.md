# 🔎 Filter Data in Excel

## 📌 Overview

In this lesson, I learned how to use **Filters in Microsoft Excel** to display only the data that matches specific conditions.

Filtering is useful when working with larger datasets because it allows us to quickly find the required records without deleting the remaining data.

---

## 🔍 What is Filtering?

Filtering is a feature in Excel that temporarily hides rows that do not match the selected condition.

The original data remains unchanged.
