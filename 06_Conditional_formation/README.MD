# 🎯 Conditional Formatting in Excel

## 📌 Overview

In this lesson, I learned about **Conditional Formatting** in Microsoft Excel.

Conditional Formatting is used to automatically change the appearance of cells when specific conditions are met. It helps to quickly identify important values, patterns, and trends in a dataset.

---

## 🔍 What is Conditional Formatting?

Conditional Formatting allows Excel to format cells automatically based on their values or specific conditions.

For example:

* Highlight marks greater than a specific value
* Highlight marks below a specific value
* Identify duplicate values
* Highlight the highest or lowest values
* Use color scales to compare values

---

## 🎨 Conditional Formatting Options Learned

### 🔹 Highlight Cells Rules

Used to highlight cells based on conditions such as:

* Greater Than
* Less Than
* Between
* Equal To
* Text That Contains

### 🔹 Top/Bottom Rules

Used to identify values such as:

* Top 10 items
* Bottom 10 items
* Top percentage
* Bottom percentage
* Above average
* Below average

### 🔹 Data Bars

Data Bars display bars inside cells according to the value of the cell.

Higher values have longer bars, making it easier to compare data visually.

### 🔹 Color Scales

Color Scales apply different colors to cells based on their values.

They help identify:

* High values
* Medium values
* Low values

### 🔹 Icon Sets

Icon Sets add symbols or icons to cells based on their values.

They can be useful for quickly understanding the performance or status of data.
