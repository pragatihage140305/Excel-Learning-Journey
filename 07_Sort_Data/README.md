# 🔢 Sort Data in Excel

## 📌 Overview

In this lesson, I learned how to **sort and organize data in Microsoft Excel**.

Sorting helps arrange data in a meaningful order, making it easier to read, compare, and analyze.

---

## 🔍 What is Sorting?

Sorting means arranging data according to a specific order.

Excel provides different sorting options for text, numbers, dates, and formatted cells.
