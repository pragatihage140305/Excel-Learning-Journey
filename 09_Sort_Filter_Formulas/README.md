# 🔎 Sort and Filter Formula in Excel

## 📌 Overview

In this lesson, I practiced working with **Sort and Filter techniques in Microsoft Excel** using an employee dataset.

The practice workbook contains employee information such as Employee ID, Name, Gender, Department, Designation, Salary, Bonus, Gross Salary, PF, Tax, and Net Salary.

The main goal of this practice was to understand how data can be organized, sorted, filtered, and analyzed efficiently.

---

## 📊 Dataset

The employee dataset contains fields such as:

- Employee ID
- First Name
- Last Name
- Gender
- Department
- Designation
- Base Salary
- HRA
- DA
- Bonus
- Gross Salary
- PF
- Tax
- Net Salary

The workbook contains approximately 100 employee records.

---

## 🔢 Sorting Practice

I practiced organizing employee data using sorting techniques.

### Sorting examples practiced:

- Sorting employee records by Employee ID
- Sorting salary-related data
- Sorting data in ascending order
- Sorting data in descending order
- Organizing records using multiple columns

---

## 🔍 Filtering Practice

I practiced using filters to display only the required employee records.

### Filtering examples:

- Filtering by Gender
- Filtering by Department
- Filtering employee records based on specific criteria
- Working with filtered employee datasets

Filtering helps to temporarily hide records that do not match the selected condition without deleting the original data.

## 🧮 Formula Practice

I also practiced working with Excel formulas while handling the employee dataset.

The practice included working with logical conditions and organizing results based on selected criteria.
